# Double exposures

Play twelve machines with two adjustable tools and two timed shutter marks.

## Sub-features

Set the two controls, run the machine and follow both loads. Each shutter records position and distance from its target. Switch between shots or scrub the film. The six advanced rigs add canopy release, powered banking, phase and pulse, a pair of mobile charges, a loaded pawl, and a three-shaft drivetrain. Refit the best single run, compare the previous setup or open a specific practice experiment.

## How to get to it (user POV)

Open Level map in One Part Missing, choose Change one thing, then Double exposures. Both shutters must match on the same run to advance.

## Driving it with verify-chaos-engine

Preconditions: launch and doctor pass with fresh profiles. Run `./scripts/verify-chaos-engine drive double-exposures`.

Play twelve rigs from the exposed navigation using touch and desktop controls. Capture a partial, select a shutter, recover the earlier setup and physically hit both marks. Reload to verify the twelve receipts, export a GIF and use the practice link.

## Gotchas

Two partial runs do not combine. A gray diamond marks the target. The trace follows the named load or rotating rim notch. Reduced motion shows the shutter results on request.
