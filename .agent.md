# Chaos Engine — Physics Sandbox

## What This Is
2D physics sandbox with retro CRT/terminal aesthetic. Fun toy, potential GitHub Pages deploy.

## Stack
- Single `index.html` + Matter.js
- Vitest for tests
- Served by `node server.js`

## URLs
- **Live:** http://192.168.68.52:3003
- **Port:** 3003

## Testing
- `npm test` / `npm run test:coverage`
- `npm run build`

## Verification (required)
Behavior and UI changes are not done until `.cursor/skills/verify-chaos-engine` has been run on the live app (`launch`, `doctor`, `drive` the affected journeys, capture evidence, `cleanup`) and `npm test` plus `npm run build` pass. New user-facing features need a `features/*.md` entry. Update the skill with `/maintain-verification-skill` when the UI changes. PR descriptions need a Verification section with journeys and evidence paths. See `AGENTS.md`.

## Gotchas
- Single-file app — all code lives in index.html
- Static files are served by `node server.js` (default port 3003; verification uses 13003)
