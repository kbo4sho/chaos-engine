# Chaos Engine — Physics Sandbox

## What This Is
2D physics sandbox with retro CRT/terminal aesthetic. Fun toy, potential GitHub Pages deploy.

## Stack
- Single `index.html` + Matter.js
- Vitest for tests
- Served by `node server.js`

## URLs
- **Live:** http://192.168.68.59:3003
- **Port:** 3003

## Testing
- `npm test` / `npm run test:coverage`

## Gotchas
- Single-file app — all code lives in index.html
- No build step, no framework
